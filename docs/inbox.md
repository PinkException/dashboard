## Future spec: Scan caching

- [2026-09-01] **Per-scan `gh` PR-read latency / no cache (from 009-04 arch + craft nits).** `scanAll` now runs one `gh api user` probe + one `gh pr list --limit 100` per jig project, serially via synchronous `execFileSync`, on the `node:http` event loop, with no per-request cache (`src/server.mjs` rescans on every `/api/data`).
